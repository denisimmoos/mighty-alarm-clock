Third beta of **Mighty Calendar Alarms**: real, fullscreen alarms from your Google Calendar events.

### What's new
* The app is now called **MCA** under its icon, so the name is no longer cut off. Inside the app it is still Mighty Calendar Alarms.
* Debug builds now have an orange icon with a **DEBUG** band and are called "MCA Debug", so you can tell them apart from this release when both are installed.
* Releases are now built and published automatically.

### Fixed in 0.9.1-beta
* The app closed right away when opened (0.9.0-beta). If you installed 0.9.0-beta, install this version over it.

### Install
Download `MightyCalendarAlarms-v0.9.2-beta.apk` below and open it on your phone. Android may ask you to allow installing apps from your browser or file manager. Updates install over the previous version and keep your profiles.
