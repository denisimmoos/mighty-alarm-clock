Fifth beta of **Mighty Calendar Alarms**: real, fullscreen alarms from your Google Calendar events. This version comes from a second review of the code.

### Fixed
* **Wi-Fi condition: the fresh Wi-Fi scan is also planned when you change a profile.** Before, switching on the Wi-Fi condition (or adding a network) only took effect for the scan two minutes before the alarm once the next alarm was set again.
* **Releases stop safely on errors.** The build no longer treats a GitHub error as "this version was never published".

### Debug build only
* The test app ("MCA Debug") is now Orange, also when it is installed over an older test app that was still Blue. A colour you pick later is kept.
* The test app no longer brings back old data through Android's automatic backup, so a reinstall starts empty.

### Known issues
* In the autumn, when the clock goes back, an event in the repeated hour (for example the second 02:30) rings one hour early.
* With the Wi-Fi condition, Android allows only a few Wi-Fi scans while the phone is in deep sleep. If a scan is refused, the check relies on an older scan result.

### Install
Download `MightyCalendarAlarms-v0.9.4-beta.apk` below and open it on your phone. It installs over the previous version and keeps your profiles.
