Fourth beta of **Mighty Calendar Alarms**: real, fullscreen alarms from your Google Calendar events. This version fixes the problems found in a careful review of the code.

### Fixed
* **A switched-off alarm no longer rings through another profile.** If two profiles matched the same event and you switched that alarm off in the first one, the second profile took the event over and rang anyway.
* **The calendar is checked right after a restart.** Before, events added or moved while the phone was off were only picked up by the next background check, up to an hour later.
* **Wi-Fi condition: fewer wrongly skipped alarms.** Two minutes before an alarm with a Wi-Fi condition, the app now asks Android for a fresh Wi-Fi scan. Before, a phone that was only in range of the chosen Wi-Fi (not connected) could count as away while it was asleep.
* **A slow or busy phone no longer removes an alarm.** When a very complex title filter gives up on an event title, the event keeps its alarm instead of losing it.
* **Restoring a backup is faster** and does only one calendar check.
* Version numbers like `1.0.0-rc2` now work for later releases.

### Known issue
* In the autumn, when the clock goes back, an event in the repeated hour (for example the second 02:30) rings one hour early.

### Install
Download `MightyCalendarAlarms-v0.9.3-beta.apk` below and open it on your phone. It installs over the previous version and keeps your profiles.
