Sixth beta of **Mighty Calendar Alarms**: real, fullscreen alarms from your Google Calendar events.

### New
* **Menu on the "Next alarm" widget.** Tap the widget to see the next alarm's event, time and profile, with these choices:
  * Event
    * **Edit event** opens the event in your calendar app.
    * **Disable this alarm** switches off only this alarm. The event stays in your calendar, and you can switch the alarm on again in the profile's list of upcoming alarms.
    * **Delete event…** deletes the event from your calendar after you confirm. For a repeating event, only this one occurrence is deleted; the rest of the series stays.
  * Profile
    * **Edit profile** opens the profile that rings for this event.
    * **Disable profile** switches off the whole profile, so none of its events ring until you switch it on again.
  * **Open MCA** opens the app.

  Without an upcoming alarm, tapping the widget opens the app as before.
  Deleting needs permission to change your calendar. The app asks the first time.

### Fixed
* The calendar access message now uses the app's name, "Mighty Calendar Alarms".

### Known issues
* In the autumn, when the clock goes back, an event in the repeated hour (for example the second 02:30) rings one hour early.
* With the Wi-Fi condition, Android allows only a few Wi-Fi scans while the phone is in deep sleep. If a scan is refused, the check relies on an older scan result.

### Install
Download `MightyCalendarAlarms-v0.9.5-beta.apk` below and open it on your phone. It installs over the previous version and keeps your profiles.
